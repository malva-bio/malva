`malva` is a single tool that allows you to go from raw sequencing reads to insights such as gene expression and gene programs, in an incredibly fast manner. `malva` enables reference-free analysis: any sequence can be queried instantaneously, without reanalysis or realignment.

What `malva` can do for you:
- (Pre)process 100M reads in less than 2 minutes (`malva index`)
- Quickly pseudoquantify references such as 3'UTRs, gene pathways, and other sequence features (`malva quant`)
- Interactive and ultrafast query and visualization of sequences in space (`malva serve`)
- Generate high-quality spatial visualizations of query sequences (`malva show`)

... all with low memory and CPU footprint - designed to be efficient, using minimal computational resources.

## Quick start
### Installation
You can install `malva` from `pip` by running the following command from a terminal

```bash
pip install malva
```

For better performance, ensure you have `htslib` installed. For instance, you can install it from `bioconda` with:
```bash
conda install bioconda::htslib
```

For macOS, there might be some additional packages that can be installed from `conda`, especially on Apple Silicon:
```bash
conda install h5py netcdf4
# then you can install malva, if it failed because of h5py and netcdf4
```

### 0. Required data
You must have a `tsv` (or `csv`) file with the following columns:

```bash
cell_bc  xcoord   ycoord
ATTAATTA 1  2
ATTCCCTA 1  3
...   ...   ...
```

This file contains spatial barcodes and their corresponding `x` and `y` coordinates, representing the spatial transcriptomics data.
This file can be generated by `spacemake` in the case of [Open-ST data](TODO), or can be found specifically for different technologies like Visium (universal file, download [here](TODO)), Curio Seeker/Slide-seq (puck-dependent, ask manufacturer), or Stereo-seq (chip-dependent, ask manufacturer).

### 1. Create an index (`malva index`)
As an example, download these files containing the sequencing reads from the [Open-ST E13 mouse head](TODO)
```bash
wget <placeholder_url>/spatial_barcodes.tsv
wget <placeholder_url>/R1.fastq.gz
wget <placeholder_url>/R2.fastq.gz
```

Then, you can create the index:

```bash
malva index \
   --reads-in R1.fastq.gz R2.fastq.gz \
   --spatial-bc-in spatial_barcodes.tsv \
   --index-out example_index
```

This command constructs an index from the raw sequence data and spatial barcodes, which will be stored in the example_index directory. Then, you can do one of the following (or all):

#### A. Ultrafast quantification of references (`malva quant`)
The `malva quant` command allows for the pseudo-quantification of gene expression profiles from spatial transcriptomics data. This can be useful for analyzing references like human 3' UTR sequences, cDNA, gene programs, and reactome pathways.

```bash
malva quant \
   --index-in example_index \
   --reference human_utr \
   --folder-out quant_output \
   --h5ad
```

#### B. Ultrafast query and visualization of sequences (`malva show`)
To create one spatial visualization per query sequence in a `queries.fasta` file

```bash
malva show \
   --index-in example_index \
   --query queries.fasta \
   --image-out example_output # output folder
```

This generates visual representations of the query sequences mapped to the spatial coordinates, saved in the specified output folder.

For a single image file for all query sequences:

```bash
malva show \
   --index-in example_index \
   --query queries.fasta \
   --image-out example_output \
   --multichannel
```

This option consolidates all query sequences into one multichannel image, useful for comparative visualization.

#### C. Interactive querying and visualization of sequences (`malva serve`)
To interactively query and visualize your data, run the malva server:

```bash
malva serve \
   --index-in example_index \
   --port 8888 \
   --address 127.0.0.1
```

This launches a local web server where you can explore and query your indexed spatial transcriptomics data interactively. Open your web browser and navigate to [http://127.0.0.1:8888](http://127.0.0.1:8888) to start using the web interface.

## Documentation
All the detail to `malva` are available in [our documentation website](https://rajewsky-lab.github.io/malva/).

We love to have an open approach to documentation. We decided to use [mkdocs](https://github.com/mkdocs/mkdocs) as our documentation backend 
to make your life easier. So, feel free to suggest changes by opening a 
[documentation-related issue](https://github.com/rajewsky-lab/malva/issues/new?assignees=&labels=docs&template=&title=)!

You can build the documentation locally by following these steps:
1. Clone this repository
   ```sh
   git clone https://github.com/rajewsky-lab/malva
   ```
2. Install the dependencies for building the documentation:
   ```sh
   pip install mkdocs-material mkdocs-autorefs mknotebooks
   ```
3. Serve mkdocs with the following command:
   ```sh
   mkdocs serve -f malva/mkdocs.yml
   ```
